Pengaturan koneksi

Gunakan URL Web App Apps Script yang telah diperbarui. Akun Google petugas harus terdaftar pada ALLOWED_EMAILS dan memiliki akses Editor ke spreadsheet.

Catatan keamanan: Jangan publikasikan spreadsheet atau endpoint untuk umum. Data NIK, alamat, nomor telepon, dan data anak harus hanya dapat diakses petugas berwenang. Gunakan deployment Apps Script yang mewajibkan login Google dan daftar email petugas yang diizinkan.

Panduan Penggunaan

Langkah ringkas untuk administrator dan petugas.

1. Memulai aplikasi

  1. Jalankan aplikasi melalui alamat HTTPS atau localhost.
  2. Pada penggunaan pertama, buat username dan password administrator.
  3. Login dan buka menu Pengaturan untuk memeriksa identitas sekolah.

2. Pendaftaran offline

  1. Buka menu Pendaftaran.
  2. Isi data calon peserta didik dan pilih program keahlian.
  3. Tekan Simpan Pendaftaran. Data tersimpan pada perangkat yang digunakan.

3. Pendaftaran online

  1. Calon peserta didik mengisi Google Form resmi.
  2. Pastikan Form sudah terhubung ke Google Sheets.
  3. Atur Apps Script sesuai petunjuk pada README-PANDUAN.txt (tanpa token integrasi).
  4. Jalankan sinkronisasi untuk menarik data online ke perangkat.

4. Sinkronisasi otomatis

Aplikasi mengirim antrean pendaftaran offline ke tab Pendaftaran Offline dan menarik respons Google Form saat sinkronisasi. Data yang belum terkirim tetap tersimpan lokal.

5. Backup

Unduh backup JSON secara berkala dan simpan di lokasi aman. Backup berisi data pribadi calon peserta didik, jadi jangan mengirimkannya ke grup publik.

6. Keterbatasan penting

  • Data lokal di HP dan komputer berbeda sampai berhasil disinkronkan.
  • Service Worker/PWA memerlukan HTTPS atau localhost. Membuka index.html langsung tidak mengaktifkan seluruh fitur PWA.
  • Login lokal pada aplikasi statis bukan pengganti sistem keamanan server untuk data berisiko tinggi.
